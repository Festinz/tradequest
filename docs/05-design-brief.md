# 05 — Design Brief (마스터 디자인 브리프)

새 Claude 대화나 디자인 작업 시 **이 문서 통째로 시스템 컨텍스트로 붙여넣으세요**.

---

## 제품 정의

**TradeQuest** — 주식 입문자를 위한 싱글플레이 RPG 모의투자 학습 플랫폼.
"주식 세계의 듀오링고 + 포켓몬"

## 타겟 유저

- 20~30대, 주식 처음 시작
- 토스/카카오뱅크 같은 깔끔한 모바일 UX에 익숙
- 게임 학습(듀오링고, 라이즈, 알라드 등) 경험 있음
- 모바일 우선, 데스크톱 보조

## 비주얼 아이덴티티

| 항목 | 방향 |
| ---- | ---- |
| 무드 | 따뜻한 미니멀 + 살짝의 게임성 (과한 네온 ❌) |
| 톤 | 친근, 격려, 약간의 유머 |
| 레퍼런스 | 토스(레이아웃) + 듀오링고(게임화) + Linear(타이포) |
| 모션 | 부드러운 ease-out, 200~300ms |
| 일러스트 | unDraw / Storyset Bro 스타일 (라인 + 단색) |

## 톤 앤 보이스

### Do
- "오늘도 들렀구나, 반가워"
- "지지선 위에서 매수했네, 좋은 판단이야"
- "이번 주 RSI 패턴이 자주 보였어"

### Don't
- 🚫 "반드시 오릅니다", "확실한 매수 시점"
- 🚫 "축하합니다!" (남발 금지)
- 🚫 너무 캐주얼한 영어 표현 ("ㅎㅇ", "ㅋㅋㅋ")

## 게이미피케이션 규칙

1. **학습 행동 > 매매 행동** EXP 분배
   - 진입 근거 작성: 20 EXP
   - AI 조언 받기: +20 (총 40)
   - 조언 후 근거 수정: +20 (총 60)
2. **하트(HP)** = 퀴즈 오답 페널티, 5시간마다 1개 회복
3. **에너지** = 일일 매매 횟수 제한 (과매매 방지)
4. **스트릭** = 연속 출석 → 7/30/100일 마일스톤
5. **트로피** = 행동 기반 (수익 자랑이 아닌 학습 마일스톤)

## 레이아웃 규칙

- 모바일 기본 너비 380px (iPhone 12~)
- 패딩: 16px / 20px / 24px (8 그리드)
- 라운드: 12px (카드) / 8px (버튼) / 999px (배지)
- 섀도: `0 1px 3px rgba(0,0,0,0.04)` (가벼움)
- 카드 간 간격: 12px
- 한 화면에 카드 5개 이상 ❌

## 화면별 핵심 UI

### 홈
- 상단: 스트릭 불꽃 + 하트 + 에너지 (3개 칩)
- 캐릭터 카드: 아바타 + 이름 + 직업 + Lv. + EXP 바
- 일일 퀘스트 3개 (체크 가능한 카드)
- 트로피 캐러셀 (획득/잠금 섞어서)
- AI 브리핑 카드 (오늘의 시장)

### 스킬 트리
- 풀스크린 SVG 트리
- 노드: 원형 아이콘 + 이름 + 상태 색
  - 회색 점선: 잠김
  - 파랑 그라데이션: 학습 가능
  - 초록: 완료
- 하단 시트: 선택된 노드 카드 (이어하기 버튼)

### 매매 화면
- 차트 중앙 (절반 이상)
- 아래 매수/매도 토글
- 진입 근거 textarea (필수)
- "AI에게 물어보기" 점선 버튼
- 매수/매도 버튼 (큰 버튼이지만 색은 차분)

### 프로필
- 캐릭터 풀샷 (스킨 적용)
- 트로피 그리드 (포켓몬 도감 스타일)
- 매매 일지 (해시태그 필터)
- 누적 통계

## 접근성

- 컬러 대비 4.5:1 이상
- 모든 인터랙션 키보드 접근 가능
- 차트 데이터는 텍스트로도 읽기 가능 (스크린리더)

## Don'ts (강조)

- 🚫 컨페티 효과로 매매 축하 (Robinhood 비판 사례)
- 🚫 단기 수익률만 강조하는 랭킹/리더보드
- 🚫 매수/매도 버튼 빨강 강조 (충동 유도)
- 🚫 "매매 1회 = 보상" 구조 (과매매 유도)
