1. 서비스 개요

1.1 문제 정의

금융 기업과 개인 투자자 모두 다음 3가지 반복 문제를 안고 있다.

Problem 1
데이터 형태 비표준
증권사·거래소·뉴스마다 데이터 스키마가 다름. 매번 파서를 새로 짠다.
Problem 2
분석 기준 분산
RSI 계산 윈도우, 과매수 임계값이 분석가마다 다름. 결과 재현성 낮음.
Problem 3
시각화 일관성 부재
대시보드마다 색·폰트·차트 종류가 달라 학습 곡선 큼.

1.2 솔루션 개요

Skills.md 라는 단일 마크다운 문서에 다음 5가지를 선언적으로 정의한다.

  1. 입력 인터페이스 — 모든 데이터를 4가지 표준 타입으로 정규화
  2. 지표 계산 규칙 — IND-001 ~ IND-012 (SMA/EMA/RSI/MACD/볼린저/OBV/HV/MDD/Sharpe/Beta/PER 등)
  3. 시각화 선택 기준 — 데이터 형태 → 차트 종류 매핑 (VIZ-001 ~ VIZ-011)
  4. 인사이트 생성 규칙 — 조건/메시지/강도/액션 (INS-001 ~ INS-012)
  5. 리포트 조립 흐름 — 4단계 stateless 파이프라인

Skills.md 만 수정하면 코드 변경 없이 새 지표·차트·인사이트가 추가된다. 분석 엔진은 이 규칙들을 결정적(deterministic)으로 적용해 어떤 투자 데이터에서도 일관된 대시보드를 생성한다.

1.3 핵심 가치 제안

🎯 일관성

동일 입력 → 동일 차트 + 동일 인사이트. 분석가가 바뀌어도 결과 재현 가능.

🔧 확장성

새 지표·인사이트 추가 시 코드 빌드 없이 Skills.md 수정만으로 즉시 반영.

🇰🇷 한국 시장 최적화

빨강↑/파랑↓ 컨벤션, 한국어 인사이트, KOSPI/KOSDAQ 일봉 무료 (네이버·Yahoo).

🤖 AI 보강

결정적 규칙 위에 Claude Haiku 가 자연어 해설을 더해 가독성 ↑.

2. 분석 흐름 설계

2.1 전체 데이터 파이프라인

분석 엔진은 4단계 stateless 파이프라인으로 구성된다. 각 단계는 입력→출력만 정의되며 캐시 가능.

1. 정규화외부 데이터 → 표준 인터페이스
→
2. 지표 계산IND 규칙 12개 적용
→
3. 인사이트 추출INS 규칙 12개 평가
→
4. 리포트 조립슬롯 매핑 + AI 해설

2.2 단계별 상세

① 정규화 단계

외부 데이터 (KIS, Yahoo, 네이버 금융, KRX OpenAPI) 를 4가지 표준 타입으로 변환:

type Candle   = { time, open, high, low, close, volume }
type Stock    = { ticker, name, market, sector, per, pbr, roe, ... }
type Position = { ticker, qty, avg_price, current_price }
type Trade    = { ticker, side, qty, price, opened_at, closed_at, pnl }

누락 거래일은 forward-fill 금지 (NULL 유지). 시계열은 오래된→최신 정렬.

4. Skills.md 설계 방향

4.1 Skills.md 의 역할

분석 엔진의 단일 진실 공급원(SSOT). 데이터 → 분석 → 시각화 → 인사이트 의 모든 규칙을 선언적으로 정의. 문서를 수정하면 코드 변경 없이 새 분석 기준이 적용된다.

4.2 5대 규칙 카테고리

§1 입력 인터페이스

Candle / Stock / Position / Trade 4가지 표준 타입. 외부 데이터는 어댑터로 정규화.

§2 지표 계산 (IND-XXX)

SMA, EMA, RSI, MACD, 볼린저, OBV, HV, MDD, Sharpe, Beta, PER, PBR — 12개 표준 지표.

§3 시각화 매핑 (VIZ-XXX)

데이터 형태 → 차트 종류. 11개 시각화 타입. 색상은 한국 컨벤션 빨강↑/파랑↓.

§4 인사이트 (INS-XXX)

조건/메시지/강도/액션 4요소. 12개 자동 인사이트 + LLM 자연어 보강.

§5 리포트 조립 흐름

4단계 stateless 파이프라인 + 8개 화면 슬롯 매핑 + 우선순위 정렬.

4.3 규칙 작성 규약 (DSL)

모든 규칙은 다음 패턴을 따른다:

### {ID-XXX} {짧은 이름}
- 수식 / 조건: {결정적이고 재현 가능한 정의}
- 윈도우 / 임계: {파라미터 명시}
- NULL 처리: {경계 케이스 정의}
- 활용 / 강도: {이 규칙이 어디에 쓰이는지}

4.5 새 규칙 추가 절차

Skills.md 에 규칙을 추가하면 코드 변경 없이 새 분석/시각화/인사이트가 활성화된다.

유형1단계2단계결과
새 지표 (IND)Skills.md §2 에 IND-XXX 정의registry.ts 에 함수 등록차트 옵션 자동 노출
새 차트 (VIZ)§3 매핑 표에 행 추가컴포넌트 + VIZ_REGISTRY 등록슬롯이 자동 선택
새 인사이트 (INS)§4 에 INS-XXX 정의insights.ts evaluator 등록다음 사이클부터 발동

4.6 LLM 가드레일

결정적 규칙(§2~§4) 위에 Claude 로 자연어 해설을 보강하되, 다음 가드레일을 적용:

  • 특정 종목의 매수/매도를 단정적으로 권하지 않음 (법적 리스크)
  • 손절을 부정적인 일로 만들지 않고 학습 신호로 다룸
  • 한국어 반말 톤, 응답 토큰 상한 600
  • 일일 30회 한도 (사용자별, ai_messages 테이블 카운트)
  • 월 사용자당 비용 목표: $0.10

4.7 데이터 무결성 원칙

  • 결정적: 동일 입력 → 항상 동일 출력
  • NULL 보존: 데이터 없으면 0 으로 채우지 않고 NULL
  • 스테이트리스: 각 단계는 독립 실행 가능
  • 캐시 가능: 60초 SWR 표준 (지표) / 5분 (스킬 콘텐츠)
  • RLS 강제: Supabase Row Level Security 로 본인 데이터만 접근

5. 확장 기능 아이디어

5.1 Phase 1 — 즉시 추가 가능 (1~2주)

📊 멀티 종목 비교

선택 종목 N개의 정규화 수익률 (시작점=100) 동시 비교. VIZ-005 활용.

🌡️ 섹터 히트맵

코스피 200 모든 종목의 일간 등락률을 섹터별로 그루핑한 한 화면 시장 지도.

💬 자연어 쿼리

"최근 1주 수익률 상위 5개", "내 포트 중 PER 가장 높은 거" → Claude 가 SQL 생성 후 실행.

🔔 인사이트 알람

사용자가 관심 종목 + 트리거 INS 선택 시 이메일/슬랙 푸시.

5.2 Phase 2 — 중기 (1~2개월)

⏪ 백테스팅 엔진

Skills.md 에 BT-XXX 규칙 신설. "RSI 30 미만 매수 + 70 초과 매도" 같은 전략을 과거 데이터로 검증.

🤖 자동 매매 일지

매매 후 30분 내 진입 근거 + 차트 스냅샷 + AI 회고 자동 저장. 주간 리포트 생성.

🌐 멀티 자산 지원

미국 주식, ETF, 채권, 암호화폐. Skills.md 에 자산군별 별도 규칙 추가.

📰 뉴스 임팩트 분석

DART 공시 + 네이버 뉴스 → Claude 가 종목 영향도 분석 → 인사이트 카드로.

5.3 Phase 3 — 장기 (3~6개월)

  • Skills.md 마켓플레이스: 사용자가 만든 분석 규칙 세트 공유. "가치투자자 v1", "단타용 v2" 등 프리셋.
  • 로보 어드바이저: 사용자 위험 성향 + 보유종목 → 리밸런싱 제안 (정보 제공만, 매매 권유 X)

KIS 개인 모드 토글로 약관(본인 계좌 한정) 자동 준수. 매매 권유성 표현 가드레일. 공개 배포에도 안전.

🔌 오픈소스 + 확장

MIT 라이선스. 다른 핀테크 팀이 Skills.md 엔진을 그대로 가져가 자사 데이터에 적용 가능. API 공개 로드맵.
